# Границы и соглашения

Каждый пункт ниже — не стилистическое предпочтение, а инвариант. Для большинства из них
существует автоматическая проверка; она указана рядом.

## Проверяются скриптами

### Граница UI

Прямые импорты `@base-ui/react` разрешены **только** внутри `packages/ui`. Вне этого
пакета запрещены и «сырые» интерактивные JSX-элементы `<button>`, `<input>`, `<select>`,
`<textarea>` — используйте публичные обёртки `Terminal*`.

```powershell
pnpm check:ui-boundary
```

Проверяет `scripts/check-ui-boundary.mjs` по всему `apps/` и `packages/`.

### Свежесть сгенерированных Protobuf-привязок

После правки любого `.proto` обязательно:

```powershell
pnpm --filter @gremuchaya/protocol generate
pnpm check:protocol-generation
```

Скрипт перегенерирует `packages/protocol/src/gen` и сравнит SHA-256 до и после.
Незакоммиченный результат генерации роняет проверку.

## Проверяются ревью и тестами

### Транспорт

Первичные бизнес-операции идут через ConnectRPC поверх **бинарного gRPC-Web**. Никаких
REST-эндпоинтов, нативного gRPC и произвольного JSON (ADR 0003, ADR 0008). Два сервера
при этом настроены по-разному: file-bridge принимает только gRPC-Web
(`connect: false`), control-plane — ещё и протокол Connect (`connect: true`), который
допускает JSON-кодирование на тех же путях. Это по-прежнему ConnectRPC, а не
произвольный JSON: правило запрещает второй прикладной транспорт, а не кодирование.

Исключения — только транспорт байтов, не операции: загрузка Yandex Maps SDK и локальный
loopback Range-поток для крупного медиа. Ещё два зарезервированы контрактом, но адаптера
в репозитории пока нет — подписанные URL объектного хранилища
(`UploadPartGrant.upload_url`) и серверные вызовы GitHub-провайдера
(`GitHubIntegrationGateway`); без внедрённого порта соответствующие RPC отвечают
`unimplemented`.

### Раскладка

Корень страницы **никогда** не скроллится: ровно `100dvh`, `overflow` документа заперт.
Скроллиться могут только ограниченные области — списки, таблицы, деревья, документы и
плитки, каждая внутри своей панели.

Свободный прямоугольник размером не меньше минимальной ячейки сетки считается дефектом,
если он явно не зарезервирован дескриптором экрана.

### Безопасность

- Загруженное пользователем содержимое **не исполняется**: произвольные HTML, JavaScript
  и CSS не принимаются ни редактором, ни настройками.
- Секреты, ключи устройств, пути файловой системы и физическое размещение окон остаются
  локальными для устройства и не синхронизируются.
- Сырые токены устройства не хранятся — только HMAC-хеши с разделением по назначению.
  Исключение одно и намеренное: учётные данные сторонних провайдеров
  (`github_installations.encrypted_credentials`) нужно тратить, поэтому они лежат
  аутентифицированным шифротекстом; ключ живёт в замыкании вызывающей стороны через порт
  `CredentialSealer` и хранилищу не принадлежит.
- Ошибки аутентификации возвращают одинаковый обобщённый ответ и не раскрывают, какая
  именно проверка не прошла.

Полный перечень инвариантов — в [`.github/SECURITY.md`](../.github/SECURITY.md).

### Offline-first

Desktop-сборка — статический экспорт Next.js плюс нативные адаптеры Tauri; во время
исполнения сервера Node нет (ADR 0005). Синхронизация окон использует типизированную шину
экранов: события Tauri в desktop, `BroadcastChannel` со `storage`-фолбэком в web —
намеренно не WebSocket, чтобы исполнение cue не зависело от сервера (ADR 0001).

Все маршруты `/screen/:id`, `/wall/:id` и `/scene/:id` генерируются статически на этапе
сборки (ADR 0006).

## Код

- Интерфейс и README — на русском; код, идентификаторы и комментарии — на английском.
- TypeScript строгий везде (`tsconfig.base.json`): `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`, `noUnusedLocals`, `noUnusedParameters`,
  `verbatimModuleSyntax`.
- Пишите код в стиле окружающего: та же плотность комментариев, те же имена и идиомы.
- Комментарий объясняет **почему**, а не пересказывает код.
- `apps/hq/AGENTS.md` перезаписывается командой `next dev` — не правьте вручную.

## Владение состоянием

- Zustand владеет текущим снимком клиентского состояния в двух хранилищах —
  `apps/hq/src/state/operationsStore.ts` и `apps/hq/src/state/appStore.ts`. На срезы по
  доменам он не разделён; план, предполагающий срезы scene/screens/workspace/explorer/
  connection, описывает цель, а не код.
- Определения сцен — неизменяемая конфигурация, а не состояние исполнения.
- Персонализацией владеет `@gremuchaya/settings-schema`: реестр определений в 32 категориях
  и трёх областях (`factory | group | device`), сгруппированные для навигации в
  `apps/hq/src/application/personalization/catalog.ts`. Новое определение по умолчанию
  `device`, а `group` берут только для того, что группа обязана видеть одинаково; сколько
  их сейчас в каждой области, отвечает сам реестр — счёт здесь устаревал дважды и потому
  не повторяется (`local-draft` и `session-preview` были объявлены и не достались никому,
  сняты 2026-08-27). Значение попадает в документ через одну таблицу
  `apps/hq/src/application/personalization/presentation.ts` плюс названный там же список
  `derivedPresentationOutputs` — то, что вычисляется из двух настроек сразу и потому
  привязкой быть не может. Тест падает на определении, которое не привязано и не отнесено
  к названному потребителю, и на выходе, который ничем не читается.
- `localStorage` владеет всем, что сохраняет браузер, — девять ключей:
  `gremuchaya-hq:operations:v3`, `gremuchaya-hq:production-snapshots:v3`,
  `gremuchaya-hq:snapshots:v1`, `gremuchaya-hq:device-session:v3` (сопряжённая сессия,
  областью ей служит база, а не адрес), `gremuchaya-hq:group-mirror:v1` (локальная копия
  облачного состояния, выкладывается через черновой ключ `…:draft`),
  `gremuchaya-hq:control-plane-address:v1` (ручной список адресов control plane, введённый
  в приложении; областью ему служит устройство),
  `hq.camera-material-assignments.v1`,
  `hq.keybinds-intro-seen.v1` и ключ Яндекс Карт
  `gremuchaya-hq:yandex-maps-v3-api-key` (устаревший `gremuchaya-hq:yandex-maps-api-key`
  только вычищается). Ключи `__gremuchaya_screen_bus_v1__`, `__gremuchaya_live_edit_v1__`
  и префикс `PlaybackSyncCoordinator` в этот счёт не входят: они пишутся и тут же
  удаляются как транспорт события `storage` и ничего не хранят. IndexedDB и плагина
  нативного хранилища Tauri в репозитории нет. Медиа и таймеры никогда не персистятся.
- Все операции ввода-вывода и межсрезовые переходы выполняют сервисы приложения;
  React-компоненты только вызывают use case и выбирают узкие срезы состояния.

## Тесты

- Тесты, требующие внешних сервисов, — opt-in через переменную окружения, по умолчанию
  пропускаются, чтобы `pnpm test` оставался офлайн и детерминированным. Пример:
  `HQ_CONTROL_PLANE_TEST_DATABASE_URL`.
- Структурный тест против замоканного клиента доказывает форму запроса, но **не**
  поведение движка: блокировки строк, сериализацию advisory-lock и то, что join
  действительно отсекает строку, доказывает только реальная СУБД. Не выдавайте одно за
  другое в отчёте.
- Отрицательный тест обязан падать при откате исправления.
